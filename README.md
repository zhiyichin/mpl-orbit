# mpl-orbit

Browser-based viewer for exploring matplotlib 3D plots through pre-rendered GIFs. Frame-by-frame playback for debugging experiment animations.

**🔗 Live demo: [mpl-orbit](https://zhiyichin.github.io/mpl-orbit/)**

## Roadmap
- [x] Single-GIF player with play/pause/step/save-frame
- [ ] Python wrapper to batch-render matplotlib 3D plots at multiple camera angles
